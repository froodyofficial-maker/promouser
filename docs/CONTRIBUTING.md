# Contributing to ProMouser

Thanks for your interest in improving ProMouser.

## Ways to contribute

- Report bugs or broken links
- Suggest improvements to guides or recommendations
- Improve clarity, accessibility, or layout
- Add or refine tools and pages
- Help with proofreading or content updates

## Before you contribute

Please keep the project lightweight and consistent with the current static-site structure:

- Prefer small, focused changes
- Keep the site simple and easy to use
- Preserve responsive behavior and accessibility
- Avoid unnecessary frameworks or heavy dependencies

## Local setup

```bash
git clone https://github.com/froodyofficial-maker/promouser.git
cd promouser
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Pull request guidelines

- Keep changes focused on one topic or fix
- Explain the purpose of the change clearly
- Test the affected pages locally when possible
- Do not add unnecessary complexity, dependencies, or visual clutter

## Reporting issues

Please use the issue templates when possible and include as much relevant detail as you can.

## Code of conduct

This project follows the Contributor Covenant code of conduct. Please review the code of conduct
before participating.
