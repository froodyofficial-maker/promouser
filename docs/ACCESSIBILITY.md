# Accessibility Statement

ProMouser aims to make its mouse and peripheral guides and online tools usable
by as many people as possible. We are working to improve accessibility as the
site evolves.

## Supported environments

The site is designed for current desktop and mobile browsers, including Chrome,
Firefox, Safari, and Edge. It uses standard HTML, CSS, and JavaScript and is
intended to support keyboard navigation and assistive technologies where the
underlying page and browser allow.

Actual accessibility can vary by page, browser, device, and assistive
technology. We do not currently claim conformance with a particular
accessibility standard.

## Known limitations

Some interactive tests and tools rely on mouse or touch input and may not offer
an equivalent experience for every input method. Some images or older content
may also have incomplete text alternatives, and accessibility has not yet been
independently audited across every page.

## Report an accessibility barrier

If you encounter a barrier, please report it through the project's GitHub issue
tracker. Include the page URL, what you were trying to do, the device and
browser or assistive technology you used, and any steps that help reproduce the
problem. Please do not include sensitive personal information.

We welcome reports and will use them to help prioritize improvements.
