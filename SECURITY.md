# Security Policy

## Supported versions

ProMouser is a static website. The latest version on the `main` branch is the
only actively supported version.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Report a suspected vulnerability privately through the repository owner's
GitHub profile or repository contact channel. Include:

- A clear description of the issue
- The affected page, file, or URL
- Steps to reproduce the issue
- Any relevant screenshots, logs, or proof of concept
- The potential impact

Please allow reasonable time for investigation and remediation before publicly
disclosing the issue.
