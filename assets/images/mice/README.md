Product images for the mice pages live in this folder.

This repo currently includes professional placeholder images with matching filenames plus WebP variants for fast loading.

To replace placeholders with real product photos, overwrite the `.jpg` file using the same filename and re-generate the WebP variants (or ask me to do it for you).
